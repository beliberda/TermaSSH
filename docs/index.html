Features

Everything you actually use, nothing you don't

Built around the daily workflow of connecting, browsing, and moving files — without the bloat.

Multi-tab SSH terminal

Run as many connections side by side as you need, each with its own independent lifecycle.

Session manager

Save, organize into folders, and import/export SSH, SFTP and FTP connections as JSON.

SFTP file browser

Browse and transfer files over the same active SSH connection — no second login.

FTP support

A standalone file browser for plain FTP servers, no terminal session required.

Flexible authentication

Password or private key auth, with key paths stored per session — never the key itself in plain config.

Dark & light themes

Plus a customizable terminal font family and size to match how you actually read a shell.

Keyboard shortcuts

Quick connect, close tab, toggle sidebar — configurable, so your muscle memory carries over.

Localized

English, Russian, German, Italian and Chinese out of the box.

Open source, MIT

Fork it, read the Rust backend, ship a patch. Nothing runs behind closed doors.
